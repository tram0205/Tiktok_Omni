Kho clip quay tay ghép CUỐI video Showcase (2–5 giây).



Cấu trúc thư mục (mỗi loại SP một thư viện; áo dài có thêm nhóm con):

  Assets\CtaBRolls\ao-dai\                 — Áo dài (gốc)

  Assets\CtaBRolls\ao-dai\hoc-sinh\       — Học sinh

  Assets\CtaBRolls\ao-dai\cach-tan\       — Cách tân

  Assets\CtaBRolls\ao-dai\mau-tron\       — Màu trơn

  Assets\CtaBRolls\ao-dai\giao-vien\      — Giáo viên

  Assets\CtaBRolls\fashion-top\           — Áo / top

  … (các loại SP khác)

  Assets\CtaBRolls\shared\                — Tự động / tuỳ chỉnh



Clip cũ đặt trực tiếp trong Assets\CtaBRolls\ vẫn dùng được cho thư viện «shared».



Cách dùng:

1. Chọn «Loại SP» (vd. Áo dài) → mở «Công cụ Video».

2. Chọn «Nhóm clip» (vd. Học sinh) → «Mở thư mục clip».

3. Thả clip → «Quét clip thật» → «Tạo kịch bản» / render.



Tắt ghép: bỏ tick «Ghép clip quay tay» hoặc Gemini trả cta_broll_id = "none".
